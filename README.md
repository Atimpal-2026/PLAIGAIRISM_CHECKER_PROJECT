# Plagiarism Checker

A Python-based web application that compares two text documents and calculates their similarity using text-processing techniques.

## About the Project

The Plagiarism Checker is a mini project developed using Python and Streamlit. It helps users compare two documents, identify exact matching sentences, and view a similarity score.

## Features

- Compare two text documents.
- Enter text manually or upload `.txt` files.
- Calculate similarity using TF-IDF and cosine similarity.
- Identify exact matching sentences.
- Display word counts and comparison results.
- Download a comparison report.

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- Regular Expressions
- SequenceMatcher

## Installation

1. Clone this repository:
   "git clone https://github.com/Atimpal-2026/PLAGIAIRISM_CHECKER_PROJECT.git"

2. Open the project folder:
   "cd PLAGIAIRISM_CHECKER_PROJECT"

3. Create a virtual environment:
   "python -m venv .venv"

4. Activate the virtual environment on Windows:
  ".venv\Scripts\Activate.ps1"

5. Install the required libraries:
   "python -m pip install -r requirements.txt"

## Run the Application

Execute the following command:

"python -m streamlit run app.py"

The application will open in your browser.
